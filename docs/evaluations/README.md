# Evaluation checkpoints

These reports preserve the verified results from Phases 4–7. Their environment
status describes the time of evaluation. Subsequent cleanup removed the dedicated
`axon-phase7` kind cluster, Axon dashboard services, demo volumes and temporary
container images. Raw local evidence remains under ignored `build/` directories.

Recreate environments using the documented evaluation/demo scripts. Generated
executables and PoC bindings/objects are disposable and are not versioned.
